# MandarCasa — Manual de Pagos Crypto-First (Fase 1)

## Principio
El cliente paga primero. Tú pagas al vendedor después de confirmar el pedido. Nunca pagues antes de recibir el dinero del cliente.

---

## Flujo de un Pedido (Crypto - Recomendado)

### Paso 1: Cliente hace el pedido
- Cliente te escribe por WhatsApp
- Le confirmas precio + tiempo de entrega
- Le das las opciones de pago

### Paso 2: Cliente paga con USDT (Solana)
- Le das tu dirección de wallet USDT en Solana
- Le indicas el monto exacto
- Esperas a que te mande el hash de la transacción

### Paso 3: Verificas el pago
- Revisa que el hash sea válido (puedes usar solscan.io)
- Confirma que el monto sea correcto
- Confirma que el pago ya llegó a tu wallet

### Paso 4: Pagas al vendedor
**Opción A (recomendada):**
- Le pagas al vendedor también en USDT (más barato y rápido)

**Opción B:**
- Le pagas por Zelle o Cash App (si el vendedor lo prefiere)

### Paso 5: Das instrucciones al vendedor
Envía este mensaje:

```
✅ Pedido confirmado y pagado.

Cliente: [Nombre]
Producto: [descripción]
Dirección de entrega: [dirección]
Entregar antes de: [hora]

Por favor confirma cuando estés en camino y mándame foto al entregar.
```

### Paso 6: Cierre
- Cuando el vendedor entregue, pide foto + confirmación
- Reenvía la foto al cliente
- Cierra el pedido


---

## Reglas de Oro

1. **Nunca pagues al vendedor antes de recibir el dinero del cliente.**
2. **Siempre confirma el hash cuando usas crypto.**
3. **Prefiere pagar a vendedores en USDT** (es más barato y rápido para ellos).
4. **Guarda captura de cada transacción** (por si hay disputas).
5. **Responde rápido.** La mayoría de clientes esperan respuesta en menos de 30 minutos.

---

**Este flujo manual es suficiente para los primeros 3 meses.**
