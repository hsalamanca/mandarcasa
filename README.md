# MandarCasa

Diaspora remittance commerce platform — connecting Salvadorans in the US with businesses in El Salvador.

## Pages

- `index.html` — Customer homepage
- `como-funciona.html` — How it works
- `proveedores.html` — Vendor recruitment
- `contacto.html` — Contact & support

## Stack

Static HTML/CSS/JS — deployed via Vercel.

## Deploy

Push to `main` branch → Vercel auto-deploys.
